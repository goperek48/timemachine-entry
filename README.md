The funniest one-line warning label for a time machine, in 120 characters or fewer, for make.fun's "Funniest Time Machine Warning Label" bounty ($2, winner takes all, judged in private rounds).

The label:

```
WARNING: Passengers who prevent their own birth will be charged a full fare and denied a refund.
```

The joke turns the grandfather paradox into a ticketing dispute: the deadliest thing you can do with a time machine is handled like a fare violation, and the punchline lands in the last words, where a safety instruction is expected and a refund policy shows up instead. Straight face throughout, no wasted words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the label verbatim to `entry.txt` in the output directory (`/output` by default), with no trailing newline, so both grading runs produce identical bytes.
